Crea OAuth Google

Per attivare Gmail e Calendar serve l'autorizzazione del tuo account Google. gog usa un client OAuth desktop tuo: nessuna password Google passa dal bot o dalla dashboard.

Come attivarlo

1. Google Cloud → Credenziali → crea un client OAuth Desktop e scarica il JSON.
2. Nel terminale: gog-secretary auth credentials set ~/Downloads/client_secret_*.json
3. gog-secretary auth add {{GOOGLE_ACCOUNT}} --services gmail,calendar --gmail-scope read-send
4. Apri l'URL, autorizza e torna qui: Verifica connessione.
Il server MCP espone solo ricerca Gmail, invio email e lettura calendario. Il bot resta senza tool finché non abiliti un flusso approvato: nessun invio automatico o evento creato da solo.

Permanente senza dominio

Se non vuoi pubblicare l'app OAuth, il bridge Apps Script usa Gmail e Calendar con un solo consenso Google. Nessun dominio da comprare e nessuna scadenza di 7 giorni.
